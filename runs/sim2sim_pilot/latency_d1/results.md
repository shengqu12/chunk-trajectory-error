## Setup

- Source: nominal ManiSkill PickCube-v1 (`physx_cpu`, `pd_ee_delta_pos`, state obs). Target: the same with a one-step command latency (d = 1; first d steps hold with the first command's gripper value). Chunk H = 20, e = 5, L = 15, K = 10, r = 0.
- Seeds [17, 18, 19, 20, 21]. Per seed a base policy (`02_prepare_policy.py` unchanged, per-seed config), then five fine-tunes from it with the 06 recipe (5000 steps, lr 3e-4, batch 256, identical demonstration batch sequence per seed).
- G: the sqrtJ gap network of Phase B (`checkpoints/gap_sqrtJ.pt`), trained **once** from pi_bc's target rollouts (pi_bc = the seed-17 BC fine-tune of `runs/maniskill_pickcube_official`) and reused frozen for all seeds.
- Selection: every candidate is run in the target from the 100 val-split seeds (200-step cap); most successes wins, ties to the smaller weight / earlier checkpoint. Final evaluation: seeds 200000-200149 (never used before), target and source, one 400-step run per episode: success@200 (primary) = success within 200 steps, success@400 (secondary).
- Intervals: two-way cluster bootstrap (5000 resamples) over seeds and initial states (true gap: seeds and logged episodes); 95% percentile intervals of the pooled paired mean difference.

## Notes

- Consistency check: in a fresh environment running only those 50 seeds, the 200-step and 400-step caps give identical outcomes per episode (13 vs 13; cap200 == cap400: True) and repeats are bit-identical (True). The 1 episode that differs from Phase A comes from the environment's history: Phase A ran 100 test-episode resets before these seeds, and PhysX carries solver state across resets. This is noise across evaluation orders, not an effect of the 400-step cap (`phase_c/consistency_diagnosis.py`).
- Every method with a weight or checkpoint choice (gap-demo, gap-logged, fine-tune, smoothness) was selected on target success over the 100 val seeds; zero-shot had a single candidate. Differences against zero-shot therefore include the benefit of target-based selection.
- Target mean steps and mean EE step are over the 400-step episodes (failures run to 400).
- G is trained once, from pi_bc's rollouts (seed 17 lineage), and reused for every seed; the other seeds' base policies never produced target data.
- Gap-network quality (Phase B, logged val states): Spearman 0.89, MAE 1.16e-05 m² vs constant 3.74e-05 m².
- Selection uses target rollouts from the val-split seeds for every method that has a weight, including smoothness (which uses no target data for training); the counts above are those selection steps.
- The true gap of each policy's own chunk is a sim-to-sim-only measurement (target restored from the Phase B val logs, including the pending command); it is not available on hardware.
